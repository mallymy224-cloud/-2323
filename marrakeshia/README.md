# مراكشية — متجر ملابس مغربي (PHP + MySQL)

متجر إلكتروني كامل بالعربية (RTL) لبيع الملابس المغربية: قفاطين، عبايات، فساتين، جلابيات، قمصان وأوشحة.
يشمل واجهة متجر، سلة تسوق، إتمام طلب، حسابات عملاء، ولوحة تحكم كاملة لإدارة المنتجات والطلبات.

> هذا المشروع مستقل داخل مجلد `marrakeshia/` ولم يتم تعديل أي ملفات HTML موجودة مسبقاً في المجلد الأصلي.

---

## 1. التشغيل على XAMPP

### المتطلبات
- XAMPP (Apache + MySQL/MariaDB) — PHP 8.0 أو أحدث.
- إصدار PHP الحالي المختبر: PHP 8.4.

### الخطوات
1. شغّل **Apache** و**MySQL** من لوحة تحكم XAMPP.
2. انسخ مجلد `marrakeshia` كاملاً إلى:
   ```
   C:\xampp\htdocs\marrakeshia
   ```
3. افتح المتصفح على:
   ```
   http://localhost/marrakeshia/install.php
   ```
4. اضغط **بدء التثبيت الآن**. سيقوم المعالج بإنشاء قاعدة `marrakeshia` واستيراد كل الجداول والبيانات التجريبية.
5. بعد نجاح التثبيت:
   - المتجر: `http://localhost/marrakeshia/`
   - لوحة التحكم: `http://localhost/marrakeshia/admin/login.php`
6. **احذف الملف `install.php`** بعد التثبيت لحماية قاعدة البيانات.

### الطريقة اليدوية (بدون install.php)
1. افتح `http://localhost/phpmyadmin`.
2. أنشئ قاعدة بيانات باسم `marrakeshia` بترميز `utf8mb4_unicode_ci`.
3. اختر القاعدة ثم **Import** واستورد الملف:
   ```
   database/marrakeshia.sql
   ```
4. تأكد من بيانات الاتصال في `config/database.php`.

## 3. إعدادات قاعدة البيانات

عند الحاجة، عدّل الملف:

```php
// config/database.php
define('DB_HOST', '127.0.0.1');
define('DB_NAME', 'marrakeshia');
define('DB_USER', 'root');
define('DB_PASS', '');
```

إذا كان MySQL لديك على منفذ مختلف، استخدم:
```php
define('DB_HOST', '127.0.0.1;port=3307');
```

## 4. مزايا المتجر

### واجهة المتجر
- صفحة رئيسية بتشكيلة مميزة وتصنيفات، مع **صورة واجهة قابلة للتغيير من لوحة التحكم**.
- المتجر مع بحث، فلترة حسب التصنيف، ترتيب حسب السعر/الأحدث، وترقيم صفحات.
- صفحة منتج بتفاصيل كاملة، صور، خصومات، مخزون و**اختيار المقاس المتاح**.
- سلة تسوق كاملة (إضافة، تعديل كمية، حذف، تفريغ) وتدعم نفس القطعة بمقاسات مختلفة.
- إتمام الطلب للزوار والمسجلين، مع **طرق دفع: الدفع عند الاستلام / مدى / فيزا** والتوصيل المجاني بعد حد معين.
- **صفحة دخول خاصة بالعميلات** توجّه إلى حساب المتجر فقط، وتدعم الدخول **بالبريد الإلكتروني أو برقم الهاتف** (منفصلة تماماً عن دخول لوحة التحكم).
- تسجيل حساب، تسجيل دخول، صفحة حسابي وسجل الطلبات.
- تصميم عربي RTL متجاوب مع الهواتف.

### لوحة التحكم
- نظرة عامة بإحصائيات المتجر وآخر الطلبات، مع زر مباشر لإضافة المقاسات.
- إدارة المنتجات: إضافة/تعديل/حذف، **رفع صورة أساسية + عدة صور إضافية للمعرض**، السعر والسعر القديم، المخزون، التمييز، النشر/المسودة، و**تحديد المقاسات المتاحة لكل منتج**.
- **وحدة المقاسات**: إضافة/تعديل/حذف المقاسات (XS, S, M, L, XL, مقاس واحد...) وربطها بالمنتجات.
- إدارة التصنيفات.
- إدارة الطلبات وتغيير حالتها (قيد الانتظار، مؤكد، تم الشحن، تم التسليم، ملغي) مع إرجاع المخزون تلقائياً عند الإلغاء، وعرض المقاس وطريقة الدفع.
- قائمة العملاء.
- الإعدادات العامة (اسم المتجر، الهاتف، العنوان، الشحن، العملة...)، **صور الواجهة والدخول**، **أيقونة الموقع وأيقونة البحث**، **تفعيل/تعطيل طرق الدفع** وتغيير كلمة مرور المدير.

## 5. الصور

الصور الافتراضية موجودة في:

```
assets/images/
├── hero.svg            صورة الواجهة الرئيسية (الافتراضية)
├── pattern.svg         زخرفة خلفية
├── placeholder.svg     صورة بديلة عند غياب صورة المنتج
├── favicon.svg         أيقونة الموقع
├── products/
│   ├── p1.svg … p12.svg   صور المنتجات التجريبية
│   └── p2.svg             الصورة الافتراضية لصفحتي الدخول والتسجيل
└── uploads/            صور الواجهة / الدخول المرفوعة من لوحة التحكم
```

### استبدال الصور
- **من لوحة التحكم:** عدّلي المنتج وارفعي صورة JPG/PNG/WEBP/GIF (أقل من 5 ميغابايت).
- **يدوياً:** يمكن استبدال أي ملف `p1.svg` … `p12.svg` بصورة بنفس الاسم، أو رفع صور جديدة واختيارها من لوحة التحكم.
- يُفضّل استخدام صور عمودية بنسبة قريبة من **3:4**.

### صور الواجهة من لوحة التحكم (إعدادان منفصلان)
من **الإعدادات** يمكنك التحكم في صورتين بشكل مستقل:

| الإعداد | يظهر في | الافتراضي |
|---|---|---|
| **صورة الواجهة الرئيسية** | `index.php` | `assets/images/hero.svg` |
| **صورة الدخول والتسجيل** | `login.php` + `register.php` | `assets/images/products/p2.svg` |
| **أيقونة الموقع (Favicon)** | تبويب المتصفح ونتائج البحث | `assets/images/favicon.svg` |
| **أيقونة حقل البحث** | مربع البحث في رأس المتجر | عدسة مكبّر مدمجة (SVG) |

لكل واحدة: رفع صورة (JPG / PNG / WEBP / GIF / SVG)، معاينة قبل الحفظ، وزر «العودة للصورة الافتراضية». تُحفظ الملفات في `assets/images/uploads/`.

### معرض صور المنتج
كل منتج يمكن أن يحتوي على **أكثر من صورة**:
- الصورة الأساسية (`products.image`) تظهر في بطاقات المتجر والسلة.
- من **تعديل المنتج → صور إضافية (معرض المنتج)** يمكنك رفع عدة صور دفعة واحدة، أو حذف صور موجودة.
- في `product.php` تظهر الصور كمعرض: صورة كبيرة + مصغّرات قابلة للنقر للتبديل.
- الصور التوضيحية `detail-1.svg` / `detail-2.svg` / `detail-3.svg` مضافة لبعض المنتجات كبيانات تجريبية ويمكن استبدالها.

### المقاسات
- من قائمة **المقاسات** في لوحة التحكم أضيفي المقاسات التي تريدينها (S, M, L, XL, مقاس واحد...).
- من صفحة تعديل أي منتج حدّدي «المقاسات المتوفرة» له.
- في صفحة المنتج تختار العميلة المقاس قبل الإضافة للسلة، ويظهر المقاس في السلة والطلب ولوحة التحكم.

### طرق الدفع
الطرق المتاحة: **الدفع عند الاستلام**، **مدى**، **فيزا**. من **الإعدادات → طرق الدفع** يمكنك تفعيل أو تعطيل أي طريقة.
عند اختيار **مدى** أو **فيزا** تظهر حقول البطاقة: اسم حامل البطاقة، رقم البطاقة، تاريخ الانتهاء ورمز الأمان (CVV)، مع تنسيق تلقائي وتحقق تجريبي (Luhn + صلاحية التاريخ).

> ⚠️ هذه الحقول **للعرض التجريبي فقط**: لا تُحفظ بيانات البطاقة في الجلسة ولا في قاعدة البيانات، ولا يُخصم أي مبلغ. في الإنتاج **لا تجمعي رقم البطاقة أو CVV على سيرفرك**؛ استخدمي بوابة دفع بتقنية Tokenization / Hosted Fields (مثل CMI / PayFort / Stripe) واستبدلي قسم التحقق في `checkout.php` باستدعاء البوابة.
>
> للتجربة استخدمي الرقم `4111 1111 1111 1111` وتاريخاً مستقبلياً مثل `12/28` وأي CVV من 3 أرقام.

### دخول العملاء مقابل دخول الإدارة
| الصفحة | الغرض | الرابط |
|---|---|---|
| `login.php` | دخول العميلة إلى المتجر وحسابها | `/marrakeshia/login.php` |
| `admin/login.php` | دخول المدير فقط إلى لوحة التحكم | `/marrakeshia/admin/login.php` |

- صفحة العميلة فيها تبويبان: **بالبريد الإلكتروني** / **برقم الهاتف**، وكلاهما مع كلمة المرور.
- `login.php` يقبل `role = customer` فقط ويوجّه دائماً إلى `account.php`؛ `admin/login.php` يقبل `role = admin` فقط.
- عند التسجيل، رقم الهاتف **إلزامي** وفريد، ويُطبّع تلقائياً (`+212612345678` ⇐ `0612345678`) ليطابق الدخول بالهاتف.
- الدخول بالهاتف لا يرسل SMS في النسخة التجريبية (لا توجد بوابة OTP)؛ كل صفحة تحتوي رابطاً للأخرى.

### إتمام الطلب يتطلب تسجيل الدخول
- `checkout.php` محمي بـ `require_checkout_customer()`: الزائرة التي تضغط «إتمام الطلب» تُوجَّه إلى `login.php?redirect=checkout` مع رسالة توضيحية، **والسلة تبقى محفوظة في الجلسة**.
- إن أدخلت بيانات النموذج قبل التوجيه، تُحفظ الحقول غير الحساسة فقط (الاسم، الهاتف، البريد، المدينة، العنوان، الملاحظات، طريقة الدفع) وتُستعاد تلقائياً بعد الدخول. **لا تُحفظ بيانات البطاقة إطلاقاً**.
- بعد نجاح الدخول أو إنشاء الحساب تُعاد العميلة تلقائياً إلى `checkout.php`، وحينها فقط تظهر خطوة الدفع. بدون نية محفوظة تُوجَّه إلى `account.php`.
- صفحات `admin/` محمية: العميلة التي تحاول فتح لوحة التحكم مباشرة تُمنع وتُعاد إلى `account.php` مع رسالة؛ أما المدير فيستمر توجيهه إلى `admin/index.php` كما كان.
- إعدادات بوابة الدفع وطرق الدفع لم تتغير.

### ترقية قاعدة بيانات مثبتة مسبقاً
إذا ثبّتّ نسخة أقدم، افتح `install.php` واضغط **«تحديث قاعدة البيانات للإصدار الجديد»**. سيضيف جداول المقاسات وعمود المقاس وإعدادات صورة الواجهة وطرق الدفع **دون حذف** المنتجات أو الطلبات الحالية.

## 7. ملاحظات أمنية

- كل الاستعلامات تستخدم **PDO Prepared Statements**.
- النماذج محمية بـ **CSRF Token**.
- كلمات المرور مشفّرة بـ `password_hash` (bcrypt).
- رفع الصور يتحقق من نوع الصورة وحجمها، ومجلد الصور يمنع تنفيذ ملفات PHP.
- **بيانات البطاقة (مدى / فيزا) لا تُحفظ إطلاقاً**: تُستخدم للتحقق التجريبي فقط ولا تُخزّن في الجلسة ولا في قاعدة البيانات. في الإنتاج استخدمي بوابة دفع بـ Tokenization ولا تمرّري CVV إلى سيرفرك.
- **فصل الصلاحيات**: `login.php` يقبل العملاء فقط، و`admin/login.php` يقبل المدير فقط، وكل صفحات `admin/` محمية بـ `is_admin()`.
- مجلدات `config/` و`includes/` و`database/` محمية عبر `.htaccess` في Apache.
- **مهم:** احذف `install.php` بعد التثبيت، وغيّر بيانات المدير الافتراضية.
- في بيئة الإنتاج، فعّل HTTPS وعدّل بيانات الدخول الافتراضية لقاعدة البيانات.
